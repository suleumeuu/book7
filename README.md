# C++ электрондық оқулық — GitHub Pages

Бұл сайт бастапқы `Cpp_oqulyk_tolyk.pdf` оқулығының мәтінін PDF ретінде көрсетеді. Мазмұн бөлімі оқулықтың мазмұнына сәйкестендірілген; тақырыпты басқанда көрсетілген бет ашылады. Әр зертханалық жұмыс астында сол тақырып бойынша YouTube іздеу сілтемесі бар.

## GitHub-қа жариялау
1. GitHub-та Public репозиторий ашыңыз.
2. `index.html`, `textbook.pdf`, `README.md` файлдарын репозиторийдің root бөлігіне жүктеңіз.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Сайт `https://USERNAME.github.io/REPOSITORY-NAME/` мекенжайында ашылады.

## Ескерту
PDF.js CDN-нен жүктелетіндіктен, сайтты алғаш ашқанда интернет қажет. Зертханалық жұмыстың беттері оқулықтың құрылымына қарай берілген навигациялық нүктелер; скан/мәтіндік PDF доторындағы кейбір тақырыптар келесі бетте жалғасуы мүмкін. YouTube сілтемелері тақырып бойынша іздеу нәтижесін ашады, нақты видео ID таңдалмаған.
